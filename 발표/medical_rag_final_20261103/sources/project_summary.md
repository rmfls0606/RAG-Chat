# 프로젝트 요약

**한 줄**: MS MARCO 기반 의료 특화 RAG로, 검색된 근거 안에서만 답하고 출처를 표시하는 의료 정보 챗봇

## 데이터
- MS MARCO QnA: 실제 Bing 검색 질문 + 질문마다 문단 10개 + 사람이 쓴 정답
- 의료 질문 선별: 의료 사이트 33개 목록 기준, 문단 10개 중 2개 이상이 의료 사이트면 건강 질문
- v1.1 (지금 기준): 문단 142,605 / 평가 550 (건강 500 + 분야 밖 50) / 검증 200
- v2.1: 문단 459,067 / 평가 650 (답 있음 500 + 답 없음 100 + 분야 밖 50)

## 파이프라인
1. bge-base-en-v1.5 임베딩 + FAISS로 후보 100개
2. MiniLM-L-6 크로스인코더 재정렬 → 상위 5개 (중복 문단 제거)
3. Qwen2.5-7B-Instruct: 문서 [1]~[5] 안의 내용으로만 답하고 문장마다 [번호] 출처
4. 재정렬 최고 점수가 기준(검증 하위 5%)보다 낮으면 답하지 않음
5. 출처 등급 표시: 공공기관 · 병원·학회 · 상업 매체 · 커뮤니티·생활 · 사전 · 기타
6. Gradio 챗봇 (Colab 공유 링크)

## 주요 결과 (v1.1, 시험 500)
- 검색 MRR@10: BM25 0.213 → dense 0.384 → MiniLM 재정렬 **0.449**
- 답변 F1 (건강 100): LLM 단독 0.207 → RAG 0.268 → RAG + LoRA **0.395** (`../results/`)
- 분야 밖 질문 거절률: 0.28 → 0.48 → **0.86**

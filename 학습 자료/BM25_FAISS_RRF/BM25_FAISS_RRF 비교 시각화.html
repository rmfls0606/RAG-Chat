하이브리드 검색 실험실

문서 12개짜리 작은 검색엔진이에요. 검색어를 넣으면 키워드 검색(BM25)과 벡터 검색(FAISS 방식)이 각자 순위를 매기고, RRF가 두 순위를 하나로 합쳐요. 아래 예시 검색어부터 눌러 보세요.

검색 A

BM25 · 겹치는 단어로 매기는 점수

검색어를 단어로 쪼갠 뒤 문서마다 그 단어가 몇 번 나오는지(TF), 얼마나 드문 단어인지(IDF), 문서가 얼마나 긴지를 따져 점수를 더해요. 막대의 마디 하나가 검색어 한 단어의 몫이에요. 행을 누르면 계산 과정이 펼쳐져요.

점수 = Σ IDF(단어) × tf·(k1+1) / ( tf + k1·(1 − b + b·문서길이/평균길이) )
같은 단어가 반복될 때 점수가 얼마나 더 오르는지
긴 문서에 주는 감점의 세기 (0이면 길이 무시)
    검색 B

    벡터 검색 · 뜻이 가까운 문서 찾기

    문서와 검색어를 숫자 벡터로 바꾼 뒤 방향이 비슷한 문서를 찾아요. FAISS의 IVF 인덱스처럼 문서를 주제별 클러스터로 미리 묶어 두고, 검색어와 가까운 클러스터 몇 개(nprobe)만 뒤져서 속도를 얻어요.

    뒤져 볼 클러스터 수. 작을수록 빠르지만 정답을 놓칠 수 있어요

    코사인 유사도 순위

      실제 임베딩은 수백~수천 차원이에요. 여기서는 이해하기 쉽게 6개 주제 축으로 줄였고, 지도는 그 6차원을 평면에 펼친 그림이에요. 순위는 6차원 벡터의 코사인 유사도로 계산해요.

      결합

      RRF · 두 순위를 하나로

      BM25 점수와 코사인 유사도는 단위가 달라 그냥 더할 수 없어요. RRF는 점수를 버리고 순위만 써서 1/(k+순위)를 더해요. 한쪽에만 나온 문서는 그쪽 몫만 받아요. 문서에 마우스를 올리면 세 목록에서 같은 문서가 함께 표시돼요.

      RRF 점수 = 1/(k + BM25 순위) + 1/(k + 벡터 순위)
      작을수록 1~2등에 몰아주고, 클수록 순위 차이를 완만하게 봐요

          RRF 최종 순위

          문서는 모두 예시로 만든 짧은 글이에요. 한국어 조사(은·는·이·가 등)는 간단한 규칙으로 떼어 내서 BM25 단어로 써요. 실제 서비스에서는 형태소 분석기를 쓰는 경우가 많아요.

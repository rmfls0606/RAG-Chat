실험 순서와 배운 점

14

평가 고치기: F1 → LLM 심판

F1은 단어 겹침만 봐서, 짧은 답을 내는 06 LoRA가 F1 최고(.349)였습니다. 14B 심판으로 다시 재니 정답률은 원본 .736 vs LoRA .450으로 뒤집혔습니다.

→ 이후 모든 실험을 심판 정답률로 비교. 심판-사람 일치 .88 (40개).

15

SFT v2: 06의 원인 고치기

06은 "정답 문단이 상위 5개 밖"인 질문을 거절로 학습했습니다. 심판으로 확인하니 그런 714개 중 500개(70%)는 실제로 답할 수 있었습니다. 원본 답 중 심판이 고른 좋은 답으로 다시 학습했습니다.

→ .450 → .724로 복구했지만 원본(.736)은 못 넘음 (자기 증류의 한계).

16

검색 × 생성 모델 비교

재정렬 앙상블로 정답 문단 포함률이 상위 5 기준 .628 → .654, 상위 10에서 .776. 생성 모델은 Qwen2.5-7B / 14B / Qwen3-8B / 14B를 같은 문단으로 비교했습니다.

→ 생성 모델 교체가 가장 큰 개선 (+4.6점, CI가 0 위). 같은 계열 크기 키우기(7B→14B)는 +2점.

17

DPO: 나쁜 답을 피하도록 학습

심판이 고른 "좋은 답 vs 오답·지어낸 답·잘못 거절" 224쌍으로 Qwen3-8B에 DPO(직접 구현, LoRA r16)를 했습니다.

→ 진짜 답 없는 질문 거절 .652 → .804, 정답률 .782 → .770 (차이 유의하지 않음).

18

프롬프트·거절 기준 조정

프롬프트 3종은 차이가 없었습니다(±0.5점). 재정렬 점수로 거절 기준을 올리면 안전성은 오르지만 정답률이 같이 떨어졌습니다.

→ 비슷한 안전성(.83)을 점수 기준으로 얻으면 정답률 .678, DPO로 얻으면 .770. 거절은 점수로 자르기보다 모델이 배우는 편이 낫다.

남은 과제

  • "녹슨 못 주사"처럼 짧은 구어 질문의 잘못 거절: MiniLM 점수 하나로 거절을 정해서 생김. 거절 신호를 앙상블 점수와 함께 쓰거나 DPO 모델에 맡기는 쪽을 검증해야 함.
  • 분야 밖 질문: DB에 건강 외 문단(약 9.8만 개)이 섞여 있어 "호주 수도"에 답함. 분야 밖 거절률 .84. 도메인 판정은 손실이 커서 뺐고, 건강 사이트 비율 같은 가벼운 신호를 시험해 볼 만함.
  • 남은 오답의 주원인은 검색: 정답 문단이 상위 10에 들어오는 비율 .776. 멘토링 피드백대로 구어체·multi-hop 평가셋을 만들어 검색을 따로 개선해야 함.
  • "의료 질문 다 답하기"까지: DB가 MS MARCO 문단뿐이라 없는 내용은 답할 수 없음. MedQuAD 등 DB 확장이 다음 단계.

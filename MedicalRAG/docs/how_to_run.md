# 노트북 실행 방법

1. 드라이브 `MyDrive/rag_msmarco/`에 `notebooks/`의 노트북을 올립니다.
   (데이터는 이미 `v11_test/`, `health/`에 있으니 노트북만 올리면 됩니다)
2. Colab에서 열고 **런타임 → 런타임 유형 변경 → A100 GPU**.
3. 위에서부터 Run all. 처음에 드라이브 연결 허용 창이 뜨면 허용.
4. 결과는 노트북마다 드라이브의 정해진 폴더에 저장됩니다 (`drive_layout.md` 참고).
5. 마지막 셀이 드라이브 저장을 마무리하고 런타임을 끕니다 (유닛 절약).

**자주 생기는 문제**
- `GPU 런타임이 아닙니다` → 3번 다시 확인
- 04 챗봇 링크는 Colab이 켜져 있을 때만 열림. 챗봇 셀 ■(중지)를 누르면 종료 셀로 넘어감
- 05 학습 중 끊기면 다시 Run all → 드라이브 체크포인트에서 이어서 학습
- 질문은 **영어**로 해야 검색이 잘 됨 (데이터가 영어)

# MedicalRAG — 의료 특화 RAG 파이프라인 (박규태)

MS MARCO QnA에서 건강 질문·문단을 추려, 검색된 근거로만 답하고 출처를 표시하는 의료 QA 챗봇을 만든 작업입니다.

```
질문 ─▶ bge-base 검색 100개 ─▶ MiniLM-L-6 재정렬 ─▶ 상위 5개 문단 ─▶ Qwen2.5-7B-Instruct (+LoRA) ─▶ 답변 + 출처 [번호]
```

## 폴더

| 폴더 | 내용 |
|---|---|
| `notebooks/v1.1/` | 지금 기준. T1 전처리 → T2 임베딩 → 03 재정렬 → 04 RAG 챗봇·평가 → 05 LoRA 학습 |
| `notebooks/v2.1/` | 먼저 해 본 v2.1 버전 (02 DB·베이스라인, 03 재정렬) |
| `results/` | 검색(`retrieval/`), 답변 평가(`generation/`), LoRA(`lora/`) 결과 요약 |
| `docs/` | 프로젝트 요약, 실행 방법, 결정 기록, 드라이브 구조, 멘토링 보고서 |

노트북은 Colab A100 기준이며, 데이터·인덱스는 용량 때문에 구글 드라이브 `MyDrive/rag_msmarco/`에 둡니다 (`docs/drive_layout.md`).
